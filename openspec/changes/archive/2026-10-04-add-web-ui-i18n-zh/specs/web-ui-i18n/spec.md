# Spec Delta

## Purpose

定义 Strata Web 界面（Chat / Monitor / About 与采样抽屉）的语言本地化：支持哪些语言、默认语言怎么定、用户如何切换并被记住、切换何时生效、哪些内容翻译、哪些内容属于不翻译的数据。

## ADDED Requirements

### Requirement: 支持的界面语言

界面必须（SHALL）提供两种语言：英文（`en`）与简体中文（`zh`）。除这两种之外的语言值必须（MUST）被拒绝并回退到默认语言判定，界面不得（MUST NOT）出现空白文案或裸键名。

#### Scenario: 切换到中文

- **WHEN** 用户在语言入口选择"中文"
- **THEN** 界面所有文案改为简体中文，`<html lang>` 变为 `zh`

#### Scenario: 请求一个不支持的语言

- **WHEN** 页面以 `?lang=fr` 打开，或本地保存的语言值是词典里没有的
- **THEN** 界面按默认语言判定渲染（英文），不报错、不空白

### Requirement: 默认语言的判定

在没有用户已保存的选择时，界面必须（SHALL）按浏览器语言决定初始语言：浏览器语言以 `zh` 开头时用中文，否则用英文。已有保存选择时，保存的选择必须（MUST）优先于浏览器语言。

#### Scenario: 中文浏览器首次打开

- **WHEN** 浏览器语言为 `zh-CN`，且本地没有 `strata.lang`
- **THEN** 界面以中文渲染

#### Scenario: 日文浏览器首次打开

- **WHEN** 浏览器语言为 `ja-JP`，且本地没有 `strata.lang`
- **THEN** 界面以英文渲染

#### Scenario: 保存的选择覆盖浏览器语言

- **WHEN** 浏览器语言为 `zh-CN`，但本地保存的语言是 `en`
- **THEN** 界面以英文渲染

### Requirement: 语言选择的持久化

用户选择的语言必须（SHALL）保存在浏览器本地存储中，并在下次打开同一地址时沿用。该选择不得（MUST NOT）上传到服务器、不得写入 Strata 目录、不得进入聊天历史或采样设置的存储内容。本地存储不可用时界面必须（MUST）仍然可用，选择在本次会话内生效。

#### Scenario: 重新打开页面

- **WHEN** 用户切到中文后关闭标签页，再重新打开 `http://127.0.0.1:8080`
- **THEN** 界面直接以中文渲染，无需再选一次

#### Scenario: 隐私模式下本地存储被拒

- **WHEN** 浏览器拒绝写入本地存储
- **THEN** 语言切换仍然生效，页面不抛错，其他功能不受影响

### Requirement: 语言入口

界面必须（SHALL）至少提供一个可见的、不需要刷新页面即可切换语言的入口，并且该入口本身在两种语言下都能被认出来。

#### Scenario: 顶栏切换

- **WHEN** 用户点击顶栏的语言按钮
- **THEN** 界面在英文与中文之间切换，按钮上显示切换后的语言标识

#### Scenario: 设置里切换

- **WHEN** 用户在 About > 设置 的语言行选择一种语言
- **THEN** 界面立即换成该语言，选择被记住

### Requirement: 切换即时生效

语言切换后界面必须（SHALL）立即以新语言重绘，不需要刷新页面。正在流式输出的回答，其外壳（状态徽章、按钮、"思考中"标题）必须（MUST）随之换语言，而回答正文必须（MUST）保持模型输出的原文。

#### Scenario: 在 Chat 标签页切换

- **WHEN** 用户在 Chat 标签页切换语言
- **THEN** 输入框提示、按钮提示、空状态文案立即变为新语言，已有的聊天内容不变

#### Scenario: 回答正在输出时切换

- **WHEN** 模型正在流式输出，用户此时切换语言
- **THEN** 已生成的回答文本不变，界面外壳与后续状态文案用新语言

#### Scenario: 在 Monitor 切换

- **WHEN** 用户在 Monitor 标签页切换语言
- **THEN** 卡片标题、表头、徽章立即换语言，并在下一次指标刷新时保持新语言

### Requirement: 首屏不闪英文

当已保存的语言是中文时，页面首次绘制必须（SHALL）直接是中文，不得（MUST NOT）先显示英文再替换。

#### Scenario: 保存了中文后刷新

- **WHEN** 本地保存的语言是 `zh`，用户刷新页面
- **THEN** 首屏可见的标签页、按钮与状态文案即为中文

### Requirement: 界面文案的翻译覆盖

三个标签页与采样抽屉的全部界面文案必须（SHALL）有中文版本，包括：按钮可见文字、`title` 提示、`aria-label` 可访问名、输入框 `placeholder`、表头、状态徽章、指标卡标签与副标题、About 事实表的键名、以及所有 toast 提示的标题与正文。词典中缺失的词条必须（MUST）回退到英文原文。

#### Scenario: 中文下的 Monitor 表头

- **WHEN** 界面语言为中文且用户打开 Monitor
- **THEN** 请求表表头显示中文（时间 / 状态 / 提示 / 复用 / 输出 / …），"Hit rate" 的悬停说明也是中文

#### Scenario: 图标按钮的可访问名

- **WHEN** 界面语言为中文，辅助技术读取附件按钮
- **THEN** 其可访问名是中文

#### Scenario: 缺词条

- **WHEN** 某个词条在中文词典里不存在
- **THEN** 该处显示英文原文，不显示键名、不显示空白

### Requirement: 数字与日期时间按语言格式化

数字分组、日期与时间的显示必须（SHALL）使用当前界面对应的语言环境，而不是浏览器系统语言。

#### Scenario: 中文界面下的请求表时间列

- **WHEN** 界面语言为中文，请求表显示某条请求的时间
- **THEN** 时间按中文语言环境格式化

#### Scenario: 累计统计里的日期

- **WHEN** 界面语言为中文，Monitor 显示"自 X 起"的累计统计
- **THEN** 星期与时间按中文语言环境显示

### Requirement: 不翻译的数据

以下内容必须（SHALL）保持原样，不受界面语言影响：模型的回答与思考内容、代码块内容、MCP 服务器名 / 工具名 / 工具描述、GPU 与 CPU 型号名、模型名、URL、以及服务端返回的错误文本。

#### Scenario: 中文界面下的服务端错误

- **WHEN** 界面语言为中文，服务器返回 `missing or wrong API key`
- **THEN** 错误文本原样显示，包裹它的提示语（如"这个服务器需要密钥…"）用中文

#### Scenario: MCP 工具名

- **WHEN** 界面语言为中文，模型调用了一个 MCP 工具
- **THEN** 工具名与工具返回内容保持原样，其状态徽章（运行中 / 完成 / 出错）用中文

### Requirement: 导出 Markdown 的本地化

导出聊天为 Markdown 时，由界面生成的结构标题必须（SHALL）按当前语言，模型输出与工具内容必须（MUST）保持原文，下载文件名前缀必须（MUST）保持 `strata-chat-`。

#### Scenario: 中文下导出

- **WHEN** 界面语言为中文，用户点击"保存此对话"
- **THEN** 文件里的段落标题是中文（如 `## 你`、`## 思考过程`），回答正文与工具调用内容不变

### Requirement: 本地化资源与应用同源

本地化所需的文案资源必须（SHALL）由同一个 Strata 服务器与应用同源提供，不得（MUST NOT）引入外部 CDN 或额外的第三方网络请求。

#### Scenario: 取回本地化脚本

- **WHEN** 浏览器请求 `/web/i18n.js`
- **THEN** 服务器返回 200 与 `text/javascript`

#### Scenario: 目录穿越仍然被拒

- **WHEN** 浏览器请求 `/web/..%2Fi18n.js` 或 `/web/locales/zh.json`
- **THEN** 服务器返回 404

### Requirement: 中文下的可读字体

界面在中文下必须（SHALL）用系统中文字体渲染汉字，不得（MUST NOT）出现缺字方块。拉丁字符与数字必须（MUST）仍用原有的界面字体。

#### Scenario: Windows 上的中文界面

- **WHEN** 在 Windows 上把界面切到中文
- **THEN** 汉字正常显示，按钮与卡片不因字体度量变化而溢出或截断

### Requirement: 英文用户不受影响

浏览器语言不是中文、且从未保存过语言选择的现有用户，看到的界面必须（SHALL）与本次改动前一致。

#### Scenario: 英文浏览器首次打开

- **WHEN** 浏览器语言为 `en-US`，本地没有 `strata.lang`
- **THEN** 界面全部文案与改动前相同，仅多出一个语言入口
